# 悦音 2.0.2

2.0.0 之后的第二个补丁版本，只修焦点相关的两个问题，不改动其他功能。已包含 2.0.1 的全部修复。

## 修复：退出播放页后按键闪退

播一首歌、退出播放页，回到列表或进设置后随便按一下方向键，App 就会闪退回桌面。

原因是播放页不显示顶部导航条，退出时导航条重新挂载，焦点交接在那一瞬间失败了，界面看起来正常但焦点其实已经空着。下一次按键就会踩到这个空焦点，直接把进程带崩。

现在焦点交接改成逐帧重试直到真正落地；同时加了一条兜底：按键派发前如果发现没有焦点，先把焦点交给常驻导航条，交不出去这一次按键就不响应。宁可少一次响应，也不会再闪退。

## 修复：导航条到设置页的焦点衔接

焦点停在顶部导航条的「设置」上时，设置页会立刻把焦点抢进左栏「播放界面」，「设置」右边的搜索和正在播放入口就再也按不到了。

现在焦点停在「设置」上时留在导航条不动，想进设置按一下方向键下；在左栏第一项按方向键上，直接回到导航条的「设置」。左栏上下键在五个分组间循环绕圈、回不到顶部导航条的问题也一并修掉了。

## 版本信息

- 版本 **2.0.2**，包名 `com.yueyin.tv`，最低 Android 6.0。
- 签名与 2.0.0 及 1.0.x 一致，可直接覆盖安装，平台配置与曲库设置保留。
- 从 2.0.0 升级即包含 2.0.1 与 2.0.2 的全部修复。
