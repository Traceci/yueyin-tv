# 悦音 2.0.4

**从这一版开始，悦音同时支持电视和手机。** 下载同一个安装包，装到电视上是遥控器界面，装到手机上是触屏界面，不用再区分版本。

---

## 一个包，两端都能装

安装包不区分设备：`yueyin-2.0.4-release.apk` 拷到电视上装，就是原来那套大屏界面；装到手机上，就是一套为手指重新设计的界面。

判断由 App 自己完成——系统上报电视（或设备没有触摸屏）就走电视界面，否则按屏幕宽度分手机与平板。不需要你在设置里选，也不会装错。

两端的曲库、平台配置、音源脚本、收藏与歌单共用同一份数据。同一台 NAS，电视上连过，手机上再连一次就能用。

**电视端这一版没有改动界面**。原来的首页宫格、遥控器快捷键、播放页三种样式、4K 密度补偿全部保持原样。

## 手机界面

不是把电视界面缩小塞进手机，而是重新写的一套：

- **导航**：竖屏是底部三档（首页 / 曲库 / 我的），横屏收成左侧图标栏，底部带迷你播放条
- **曲库**：专辑、歌手、歌单、歌曲、收藏五个分段，全部按触屏滚动
- **播放页**：封面、歌词、进度拖动都支持手指操作；横屏自动切成左右分栏
- **搜索**：边输边搜，支持拼音首字母（输入 `zjl` 也能找到「周杰伦」）
- **设置**：播放界面、音效、存储与缓存、关于，都收在「我的」里，不再单独占一个 tab

## 手机横屏的一轮修复

横屏是手机版问题最集中的地方，这一版专门修了五处：

- **「我的」页明明登录了飞牛，却显示「未连接平台」** —— 判断逻辑把「当前就是飞牛会话」误当成「没有连接任何平台」。已修正，现在与电视端显示一致。
- **切换平台后，「最近播放」里还留着上一个平台的歌，点了播不出来** —— 历史记录原本不分平台。现在按平台分别记录，切回来历史还在；点一首在当前平台找不到的，会按歌名再搜一次。
- **切到「在线音乐」后，副标题还挂着 NAS 的名字** —— 在线音乐的曲库来自音源脚本，与 NAS 无关，此处不再拼接服务器名。
- **横屏状态下顶部状态栏一直占着一条** —— 现在横屏自动隐藏（从顶部下滑仍能临时唤出），竖屏正常显示，转屏即时生效。
- **横屏内容太空：专辑只有 4 列、歌手只有 2 列，封面偏大** —— 列数改为按可用宽度自动计算，横屏手机上专辑 / 歌单 / 歌曲变成 5 列，歌手 3 列；曲库顶部分段条等分铺满；首页的入口卡从两张扁宽大卡改成四张；「我的」页横屏拆成左右两栏，减少无谓的纵向滚动。

另外去掉了「我的」页底部两行说明文字。

## 安装

- 直接覆盖安装即可，签名与 2.0.0 之后的版本一致，平台的地址、账号、曲库配置与收藏都会保留
- 最低 Android 6.0；电视推荐 Android TV 9 及以上
- `universal` 包已包含 `arm64-v8a / armeabi-v7a / x86 / x86_64`，不用挑架构

从 2.0.3 升级会收到应用内更新提示；版本号已升到 2.0.4（versionCode 28）。

## 已知限制

- **手机界面是这一版才并入的**。首次使用引导在手机上暂时跳过，直接进主界面；播放队列排序、搜索「全部结果」分页、播放页「更多」菜单等细节仍在补齐，遇到问题欢迎反馈。
- 飞牛远程登录（FNID）不可用，请填局域网 IP 或可直接访问的域名。
- 在线音乐依赖第三方接口，平台侧调整后可能阶段性不可用；播放需要你自己导入音源脚本，悦音不内置任何音源。
