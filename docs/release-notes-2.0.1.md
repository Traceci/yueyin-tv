# 悦音 2.0.1

2.0.0 之后的补丁版本，集中收口设置页的焦点衔接，不改动其他功能。

## 导航条到设置页的焦点衔接

2.0.0 里把焦点停在顶部导航条的「设置」上时，设置页会立刻把焦点抢进左栏「播放界面」，导航条随之失焦——「设置」右边的搜索和正在播放入口就再也按不到了。

现在焦点停在「设置」上时留在导航条不动，想进设置按一下方向键下；在左栏第一项按方向键上，直接回到导航条的「设置」。

同时修掉了左栏上下键在五个分组间循环绕圈、回不到顶部导航条的问题。

## 版本信息

- 版本 **2.0.1**，包名 `com.yueyin.tv`，最低 Android 6.0。
- 签名与 2.0.0 及 1.0.x 一致，可直接覆盖安装，平台配置与曲库设置保留。
