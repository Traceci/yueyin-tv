# 悦音 2.0.6

这一版三条线：**车机适配**、**播放稳定性修复**、**手机端界面收口**。同一个安装包同时支持电视、手机与车机，签名与 2.0.5 一致，可直接覆盖安装。

---

## 车机

- **车机识别更准**：先判断电视，再判断车载（`UI_MODE_TYPE_CAR` / `FEATURE_AUTOMOTIVE`），最后才用「无触摸屏」兜底，车机不会再被当成电视界面。
- **车机布局档**：触控目标 56dp、侧栏 88dp、卡片最小宽 180dp；8:3 这类超宽短屏自动单列显示。
- **封面更清晰**：新增 1200 / 1600 像素两档封面，按实际显示尺寸自动升档，不拉伸。
- **车机媒体库**：Android Automotive 上可浏览「当前播放队列」与「正在播放」，支持按歌名搜索并直接起播。
- **界面形态可手选**：设置 → 播放设置 →「界面形态」，可选 `自动 / 车机 / 手机`，识别不理想时可手动切换。

## 播放

- **直链过期问题**：在线直链带时效，之前缓存不过期，换源和重试仍在用失效地址。现改为 5 分钟有效期，播放失败立即作废并重新取链。
- **空地址处理**：取不到直链时不再自动跳下一首，改为就地重取（最多 3 次）；「重试」按钮改为真正重新取链后重新播放。
- **探活更严格**：排除 HTML / JSON / 纯文本响应，统一请求头与 UA，允许跨协议重定向，避免把错误页当音频。
- **队列地址被覆盖**：修复取到新直链后被队列里旧地址覆盖、导致所有音源都提示连接失败的问题（电视端同样受影响，一并修复）。

## 手机

- 横屏「我的 → 播放界面」两张样式预览卡不再占满整屏。
- 竖屏播放页：曲名与歌手移到封面上方，封面位置与尺寸不变；下方改为三行歌词（上一句 / 当前句 / 下一句）。
- 全歌词页补齐底部常驻控制栏（进度、切歌、收藏、循环、队列、音效），歌词每行水平居中、当前句居中放大。
- 「逐字填充」在手机全歌词页生效，跟随设置里的开关。
- 竖屏不再隐藏状态栏，只有横屏隐藏。

## 说明

- 电视端界面本轮未做改动；共用层的封面解码修正会让电视封面更清晰。
