# 悦音 2.0.5

这一版继续打磨手机端体验，集中在两件事：**横屏全屏沉浸**和**平台管理改版**。同一个安装包同时支持电视与手机，签名与 2.0.4 一致，可直接覆盖安装。

---

## 横屏全屏沉浸

手机横屏时，首页 / 曲库 / 我的 / 播放页现在都贴边显示，去掉了之前左右两侧多余的留白，横屏不再空一大片。

## 平台管理改版

- **点一下就切换**：在平台列表里点任意一行，立即把它设为当前音源并生效，不用再进二级菜单。
- **删除更顺手**：每行末尾的「删除」直接删除该平台，不再弹二次确认。
- **去掉冗余入口**：移除了「编辑 / 设为当前 / 收起」等展开逻辑，界面更简洁。
- **空状态更干净**：没有添加任何平台时，页面只显示「＋ 新增平台」。
- **「我的」页**：移除了不再需要的「断开飞牛音乐」入口。
