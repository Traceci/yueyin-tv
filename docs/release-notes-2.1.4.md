# 悦音 2.1.4

同一个安装包同时支持电视、手机与车机，签名与 2.1.3 一致，可直接覆盖安装。

## 改进

1. **电视歌词定位与滚动**（CD 唱片 / 大海报）
   - 当前句对齐到歌词区的垂直中心；原来是贴顶，偏上将近四分之一屏。
   - 换句改为按播放进度连续上滑，不再是「整行跳一下」。
   - 亚像素补偿，消除慢速滚动时的细微抖动。
   - 手动翻看时自动让位（手机端 3 秒内不会被拽回）。

2. **大海报模式过渡重做**
   - 封面完整显示，不裁切、不横向拉伸。
   - 右缘经同尺寸模糊层自然淡出到取色背景。
   - 修复上一版的重影与竖直分界线。

3. **手机投播提示更低调**
   - 通栏改为贴左短胶囊，底色不透明度 78% → 40%。
   - 「停止投播」改为淡色「停止」。
   - 设备名不再显示 IP。

## 修复

4. **播放中断减少**
   - 当前曲目进入最后 20 秒时提前为下一首取直链，原来要等切歌才发现没链。
   - 取链失败重试从 2 次 / 500ms 改为 3 次退避（600ms → 1200ms）。

## 已知问题

- 首次投播仍可能从头播放（DLNA 设备侧 Seek 时机问题，未解决）。
- 个别曲目音源失效时会自动跳过，属音源侧。
